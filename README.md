# Cars

A single-page HTML/CSS website that visualizes the top 10 fastest production cars as a horizontal bar chart, built entirely with vanilla CSS (no JavaScript or chart libraries).

Features
Top 10 fastest cars ranked by top speed (mph), each with its own labeled, color-coded bar
Bar width scaled relative to speed to give a quick visual comparison between cars
A header banner and a navigation bar styled with hover effects
Fully self-contained: all styling is in a single <style> block, no external CSS or JS files
